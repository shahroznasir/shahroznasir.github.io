## ✨ Features & Interactive WOW Modules

- **🌌 Obsidian & Neon Aesthetic (`#050816`)**: Minimalist, dark-mode design inspired by Apple product pages and Linear's engineering workspace.
- **💻 3D Holographic Developer Workspace**: Built using **Three.js WebGL**, rendering an interactive 3D Laptop with glowing code screens and mouse parallax physics.
- **⚡ Terminal Boot Sequence Loader**: Simulated OS boot screen (`Initializing Portfolio... Ready.`) that explodes into a GSAP motion hero reveal.
- **⌨️ Command Palette (`Ctrl + K` / `Cmd + K`)**: VS Code style instant-search navigation overlay.
- **🖥️ Hacker Terminal ($ CLI)**: Interactive shell parsing `$ help`, `about`, `projects`, `skills`, `contact`, and `matrix`.
- **🤖 AI Assistant Chatbot**: Floating bot drawer answering queries about Shahroz's skills, experience, and background.
- **🔊 Web Audio API Synthesizer**: Pure Web Audio API sound effects on button hover, clicks, and theme switching (with a mute/unmute toggle).
- **🕹️ Konami Code Easter Egg (`↑ ↑ ↓ ↓ ← → ← → B A`)**: Unlocks Cyberpunk Matrix Mode!
- **🎨 5-Theme Engine**: Toggle seamlessly between `Dark` (default), `Midnight`, `Cyberpunk`, `Ocean`, and `Aurora` color palettes.
- **🌐 Live GitHub API Integration**: Real-time fetch of repository metrics, star counts, and top languages from `api.github.com/users/shahroznasir`.
- **📱 1-Click Mobile vCard (.vcf) Contact Card**: One-click contact download to save Md. Shahroz Nasir directly into phone address books.
- **📖 3D Interactive Education Book**: Openable 3D diploma card detailing degree achievements and coursework.
- **📱 100% Mobile View Responsiveness**: Adapted layout, canvas camera distance, and touch targets for iOS Safari and Android Chrome.

## 🛠️ Technology Stack

- **Core**: HTML5, CSS3 (Vanilla Design Tokens), JavaScript (ES6+)
- **3D Graphics & Physics**: [Three.js](https://threejs.org/) WebGL Engine
- **Motion & Scroll Animations**: [GSAP (GreenSock)](https://greensock.com/gsap/) & ScrollTrigger
- **Sound Engine**: Web Audio API Frequencies
- **API**: GitHub REST API
- **Icons**: [Boxicons](https://boxicons.com/) & Google Fonts (`Syne`, `Outfit`, `Playfair Display`, `Fira Code`)
- **Deployment**: Vercel & GitHub Pages

## 🚀 Quick Start (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shahroznasir/DEMOPortfolio.git
   cd DEMOPortfolio
   ```

2. **Run a local development server:**
   ```bash
   python -m http.server 8000
   ```

3. **Open in browser:**
   Navigate to `http://localhost:8000`.
